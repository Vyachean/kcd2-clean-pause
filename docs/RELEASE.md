# Retail release pipeline

Installable Clean Pause packages are generated by GitHub Actions. Binary ZIPs and retail game profiles must not be committed to Git.

## Why the retail profile is an external CI input

The official KCD2 mod path used by Clean Pause overrides `Libs/Config/defaultProfile.xml` as a whole file. The repository therefore needs the exact profile from the target retail build when it creates an installable package.

For the Xbox Store / Xbox app / Game Pass 1.5.6 acceptance target, the verified source profile has SHA-256:

```text
69ad9fd618cd31961fef8eb061f3f2723997df5e0fb257ec74d0d5f555592565
```

The profile itself is not stored in Git. GitHub Actions receives a gzip-compressed, base64-encoded copy through the repository secret:

```text
KCD2_XBOX_156_DEFAULT_PROFILE_GZIP_B64
```

The release workflow decodes the secret and refuses to build unless the decoded bytes match the expected SHA-256 above.

## Publishing a candidate

Workflow:

```text
.github/workflows/release.yml
```

It is manually dispatched with a release tag and title. For example:

```text
tag:        xbox-1.5.6-test1
title:      KCD2 Clean Pause — Xbox 1.5.6 test1
prerelease: true
```

The workflow then:

1. checks Lua syntax and runs the unit tests;
2. materializes the exact retail profile from the Actions secret;
3. verifies its SHA-256;
4. calls the repository-owned `tools/build_from_profile.py` builder;
5. validates both the outer install ZIP and inner game PAK;
6. generates `SHA256SUMS.txt`;
7. uploads the same files as a GitHub Actions artifact;
8. publishes them as GitHub Release assets.

The generated asset name is derived from the tag, for example:

```text
kcd2-clean-pause-xbox-1.5.6-test1.zip
```

## Required repository secret

The secret is configured once through the GitHub repository UI:

```text
Settings
  -> Secrets and variables
  -> Actions
  -> New repository secret
```

Name:

```text
KCD2_XBOX_156_DEFAULT_PROFILE_GZIP_B64
```

The value is the gzip+base64 representation of the exact verified retail `defaultProfile.xml`. Do not use the patched profile produced by Clean Pause.

## Repository policy

- never commit `defaultProfile.xml` from the game;
- never commit generated `.pak` or `.zip` files;
- `release/` and `*.zip` remain ignored;
- CI artifacts are temporary convenience outputs;
- GitHub Releases are the canonical downloadable retail candidates;
- every release candidate must identify the source-profile SHA-256 used to generate it;
- changing the supported KCD2 retail profile requires updating the verified digest and documenting the new target before publishing a release.
