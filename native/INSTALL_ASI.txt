Fresh installation:
1. Close Kingdom Come: Deliverance II.
2. Remove any standalone Clean Pause version.dll installation.
3. Open the directory containing the KCD2 executable / WHGame.dll.
4. Copy both dinput8.dll and KCD2CleanPause.asi from this package into that same directory.
5. Start the game normally.

Existing ASI loader:
If another mod already installed a compatible dinput8.dll, do not overwrite it blindly.

KCD2CleanPause.asi must be placed where that existing ASI loader actually searches for plugins. With Ultimate ASI Loader, the simplest shared-loader layout is to place KCD2CleanPause.asi beside the existing dinput8.dll. Ultimate ASI Loader can also load plugins from its scripts/ and plugins/ directories.

Do not leave dinput8.dll in one directory and place KCD2CleanPause.asi beside WHGame.dll in another directory unless that loader is explicitly configured to scan the latter location.

Do not install the ASI edition together with the standalone Clean Pause version.dll edition.

Runtime smoke:
1. Load into gameplay.
2. Press Escape / Xbox Start and confirm Clean Pause retains the gameplay frame/HUD/subtitles.
3. Press Escape / Start again and confirm the normal vanilla pause menu appears.
4. On controller, Xbox B from Clean Pause should reveal the normal pause menu.
5. Resume normally and repeat several cycles.

The native log records build identity, exact-profile or compatibility-fallback selection, environment/framework locator strategy, capabilities, and hook installation.

Troubleshooting:
If no kcd2_clean_pause_native.log is created, verify that the ASI loader is actually loading KCD2CleanPause.asi from its configured plugin location. Do not disable Defender or Smart App Control, add exclusions, or whitelist the module to work around a security block; report the exact candidate/hash instead.

Process lifetime:
Native hooks are process-lifetime state. Hot-unloading or hot-reloading KCD2CleanPause.asi while the game is running is not supported. Stop KCD2 before replacing, removing or moving KCD2CleanPause.asi.

Uninstall:
Close KCD2 and remove KCD2CleanPause.asi plus the optional kcd2_clean_pause_native.log. Remove dinput8.dll only if no other installed mod needs that ASI loader.
