KCD2 Clean Pause — ASI installation

Requires: Ultimate ASI Loader x64
Official project: https://github.com/ThirteenAG/Ultimate-ASI-Loader

1. Close Kingdom Come: Deliverance II.
2. Download the x64 dinput8 build of Ultimate ASI Loader from its official releases.
3. Place the loader as dinput8.dll beside the KCD2 executable / WHGame.dll.
4. Copy KCD2CleanPause.asi from this package into the same directory.
5. Start the game normally.

Do not install this ASI package together with the standalone Clean Pause version.dll package. They contain the same mod and would load it twice.

Multiple ASI mods may share one compatible ASI loader. Do not overwrite an existing dinput8.dll blindly; if a compatible ASI loader is already installed, keep that one and add only KCD2CleanPause.asi.

Ultimate ASI Loader also supports ASI files in scripts/ or plugins/, but the initial KCD2 Clean Pause release uses the game-root layout above because that is the simplest acceptance baseline.

The mod writes kcd2_clean_pause_native.log beside KCD2CleanPause.asi.

Uninstall:
Close KCD2 and remove KCD2CleanPause.asi and the optional kcd2_clean_pause_native.log. Remove dinput8.dll only if no other installed mod needs that ASI loader.
