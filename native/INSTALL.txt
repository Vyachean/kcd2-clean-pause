KCD2 Clean Pause v0.1.0
Target: Kingdom Come: Deliverance II 1.5.6, Windows retail
Primary tested storefront: PC Xbox Store / Xbox app / Game Pass

INSTALL
1. Close KCD2 completely.
2. Remove/disable older Clean Pause files under Documents\kingdomcome_mods\clean_pause.
3. Extract version.dll from the release ZIP.
4. Place version.dll beside the KCD2 executable / WHGame.dll.
5. Start KCD2 normally.

Do not overwrite an unrelated mod's version.dll. If another mod already uses that proxy DLL, the two require an explicit compatibility solution.
Do not change WindowsApps ownership or weaken Windows permissions solely for this mod.

CONTROLS
Running:
  Escape / Xbox Start -> Clean Pause

Clean Pause:
  Escape / Xbox Start -> visible vanilla pause menu
  Xbox B               -> visible vanilla pause menu

From the visible vanilla menu, use normal KCD2 controls to resume or choose another menu action.

EXPECTED CLEAN PAUSE
- World/simulation stops.
- Audio pauses like ordinary vanilla pause.
- The ordinary pause menu is not drawn.
- Already-visible subtitles/HUD may remain visible.
- The strong vanilla pause depth-of-field blur remains; this is intentional.

KNOWN V0.1.0 BEHAVIOR
Xbox B does not resume directly from Clean Pause. It reveals the ordinary pause menu. Resume normally from there.

LOG
kcd2_clean_pause_native.log is written beside version.dll. Keep it if behavior differs from the above.

UNINSTALL
Close KCD2, then delete only this mod's version.dll and optional kcd2_clean_pause_native.log.
